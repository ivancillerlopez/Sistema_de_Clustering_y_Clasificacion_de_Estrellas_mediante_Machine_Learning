# Clustering y Reducción de Dimensionalidad - Aprendizaje Automático (AA)

Práctica 2 de la asignatura **Aprendizaje Automático (UC3M)**.

---

## Descripción

Aplicación de técnicas de **Aprendizaje No Supervisado** para el descubrimiento de patrones y agrupamiento de datos astronómicos.

### Fases del Proyecto:
1. **Preprocesamiento:** Codificación de variables categóricas (`Spectral_Class`, `Color`) y estandarización de variables numéricas.
2. **Reducción de Dimensionalidad:** Aplicación de PCA (Análisis de Componentes Principales) y visualización de la varianza explicada.
3. **Algoritmos de Clustering:**
   * **K-Means:** Optimización del número de clusters con el Método del Codo y análisis de Silhouette.
   * **DBSCAN:** Detección de clusters de densidad y ruido.
   * **Clustering Jerárquico:** Dendrogramas y análisis de distancias (Single, Complete, Ward).
4. **Evaluación Comparativa:** Análisis de coherencia y métricas de calidad de agrupamiento.

---

## Tecnologías
